# String Validation for the Grammar S → 0A1, A → 0A | 1A | ε

## Aim

To write a C program to check whether a given string belongs to the grammar:

```
S → 0A1
A → 0A | 1A | ε
```

## Project Description

This project implements a C program to verify whether a given binary string is generated by the specified context-free grammar. The grammar generates strings that begin with `0`, end with `1`, and may contain any combination of `0`s and `1`s in between.

## Features

- Checks whether the input string satisfies the given grammar.
- Accepts binary strings over the alphabet `{0,1}`.
- Rejects invalid symbols.
- Displays whether the string is accepted or rejected.
- Simple and efficient implementation in C.

## Language

- C

## Algorithm

1. Read the input string.
2. Check whether every character is either `0` or `1`.
3. Verify that the first character is `0`.
4. Verify that the last character is `1`.
5. If all conditions are satisfied, accept the string.
6. Otherwise, reject the string.

## Time Complexity

**O(n)**

where **n** is the length of the input string.

## Space Complexity

**O(1)**

## Sample Input

```text
001101
```

## Sample Output

```text
Accepted
```

## Result

The C program successfully checks whether the given input string belongs to the grammar **S → 0A1, A → 0A | 1A | ε** and correctly displays whether the string is accepted or rejected.
